OneSomatic

OneSomatic is the home of somatic practice: a verified directory and practice software for somatic practitioners. It started in Germany in June 2025 as Kaufmann Health, where practitioners use it for booking, video sessions, invoicing and payments. In the US, the directory is live at onesomatic.com, and the practice tools come next.

More than 350 clients and 50 practitioners signed up, with 44 verified practitioner profiles and more than 150 client bookings since Jan 2026.

I built it with AI agents, with about 7,000 commits since August 2025.

onesomatic.com Practitioner directory

Security

The platform processes health data under GDPR, so I put a lot of effort into access rules and security. Every table and storage bucket carries a data classification, enforced by a failing CI test. Row-level security, grants and SECURITY DEFINER functions in Postgres are audited daily and on every change to a migration. Each push runs a test suite in GitHub Actions and deploys only when it passes. Payments go through Stripe Connect, and for scheduling we use a self-hosted Cal.com instance. This way I rely on externally audited software for the critical flows.

Data

My strong preference is for decisions to be data-informed wherever possible. I query the production data directly and track search demand through Google Search Console.

Product

The SaaS-stack I built over time gives practitioners a suite of tools, many of them completely free. With those, practitioners can showcase their credentials on their practice websites and accept intro-calls through OneSomatic, replacing costly tools for them.

Clients can browse the practitioner directory or get matched with a practitioner, upon which they can easily book the first conversation. Email and SMS carry the reminders and follow-ups after that, in German or in English depending on the user, in a fully automated fashion. Practitioners get their own automated flow, from signup/onboarding to a subscription that Stripe bills and renews.
